KONE Elevator on a phone
========================

The Windows EXE cannot run on Android or iPhone.
Use the contents of the `web` folder for the phone version.

GitHub Pages:
1. Create a GitHub repository.
2. Upload everything INSIDE `web` to the repository root.
3. Settings -> Pages -> Deploy from a branch -> main -> /root.
4. Open the HTTPS address on the phone.
5. Android Chrome: Install app / Add to Home screen.
6. iPhone Safari: Share -> Add to Home Screen.

The included manifest and service worker make the site installable as a PWA.
