# KONE Elevator — Windows + Phone

Эта версия использует один и тот же интерфейс на компьютере и телефоне.

## Карты
- **Оригинал** — этажи от -10 до 1 000 000.
- **Башня 1000** — этажи от -10 до 1 000.
- **Мегабашня** — этажи от -10 до 10 000 000 000 000.

Остальная логика симулятора сохранена.

## Windows: один EXE
1. Дважды нажмите `BUILD_EXE.bat`.
2. Скрипт использует уже установленный Python 3.13.
3. После успешной сборки откроется папка `dist`.
4. Готовый файл: `dist\KONE_Elevator.exe`.
5. Его можно переместить на рабочий стол или другой диск — соседние файлы для запуска не нужны.

`BUILD_EXE.bat` также создаёт `dist\KONE_Elevator_Windows.zip`, который удобно загружать в интернет.

После строки `SUCCESS` окно CMD можно закрывать. Сам EXE собран с `--windowed`, поэтому при обычном запуске консоль не открывается.

## Телефон: Android / iPhone
Windows-файл `.exe` на телефоне не запускается. Для телефона используется та же игра из папки `web` как PWA.

Самый простой вариант — GitHub Pages:
1. Создайте публичный репозиторий GitHub.
2. Загрузите **содержимое** папки `web` в корень репозитория.
3. Settings -> Pages -> Deploy from a branch -> `main` -> `/root` -> Save.
4. Откройте выданную HTTPS-ссылку на телефоне.
5. Android/Chrome: `Install app` или `Add to Home screen`.
6. iPhone/Safari: `Поделиться` -> `На экран Домой`.

После установки PWA выглядит как отдельное приложение и запускается с иконки KONE.

## Откуда EXE берёт картинки и звуки
Внешний API для ресурсов не используется. `PyInstaller --onefile` упаковывает папку `web` (HTML, CSS, JavaScript, картинки и WAV) внутрь EXE. При запуске Windows временно распаковывает эти ресурсы во внутреннюю временную папку, а `pywebview` открывает локальный `index.html` в отдельном окне WebView2.

Поэтому готовый EXE можно перемещать отдельно. Интернет для локальных текстур и звуков не нужен.

## Где бесплатно раздавать
- **GitHub Releases** — удобно публиковать `KONE_Elevator_Windows.zip` или `.exe`.
- **GitHub Pages** — бесплатная телефонная/PWA-версия.
- **itch.io** — подходит для бесплатной раздачи игры и браузерной версии.

## Исходники
- `app.py` — Windows-оболочка pywebview.
- `web/index.html` — интерфейс и игровая логика.
- `web/assets/` — локальные текстуры, звуки и иконки.
- `app.ico` — иконка Windows EXE на основе KONE-логотипа.


## Обновление: ошибка передачи управления АВТО
В режиме смены, если выключить АВТО, вручную выбрать этаж, забрать пассажира и затем снова включить АВТО, старая ручная команда может остаться текущей целью. Если из-за этого пассажир будет доставлен не на свой этаж, блок «Мысли АВТО» и уведомление объяснят, что АВТО опередил сам себя и использовал старую ручную команду. Остальная логика сохранена.
